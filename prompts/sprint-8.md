# Sprint 8 — 前端：整合測試 + 收尾

## 目標
全流程 UI 驗證、權限顯示測試、UI 收尾。

---

## 全流程 UI 測試

### 情境 1：Owner 初始化
註冊 → 建診間 → 建人員+指派 → 設權限 → 建初診表範本 → 建同意書範本 → 設費率+套餐 → 設通知範本。每步驟 UI 操作流暢無卡頓。

### 情境 2：完整個案流程
新增個案 → 個案用預設密碼登入 → 強制改密碼頁 → 行政代預約 → 簽同意書（SignaturePad）→ 心理師寫初診評估（FormRenderer）→ 寫晤談紀錄（SoapEditor）→ 鎖定 → 確認收款 → 常態性預約 → 套餐購買 → 扣次 → 通知顯示 → 備忘記錄 → 結案

### 情境 3：雙角色切換
心理師登入 → 選 Therapist 進後台 → RoleSwitcher 切到 Client → 進個案端 → 預約 → 切回 Therapist → 確認預約在排程上。兩個介面風格正確切換。

### 情境 4：個案端全流程
個案登入 → Dashboard 看到預約 → 新增預約（三步驟）→ 取消/改期 → 查看同意書 → 通知列表 → 設定通知偏好

## 權限顯示測試

4 種角色各登入，驗證：

| 項目 | Owner | Therapist | Admin | Client |
|------|-------|-----------|-------|--------|
